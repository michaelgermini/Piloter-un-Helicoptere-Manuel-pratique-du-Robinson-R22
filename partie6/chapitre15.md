# Chapitre 15 – Maintenance et inspection pilote

## Vérifications de routine

Le pilote d'hélicoptère assume une responsabilité directe dans la maintenance préventive de son appareil. Ces vérifications quotidiennes constituent la première barrière contre les pannes.

### Inspection pré-vol complète

**Préparation mentale** :
- Revue des bulletins de service (SB) applicables
- Vérification des composants life-limited
- Consultation du journal de maintenance

**Équipement requis** :
- Lampe torche puissante
- Miroir d'inspection (long manche)
- Jauge de pression pneus
- Multimètre (tension batterie)
- Huile de référence (visuelle)

### Séquence systématique

**Marche autour extérieure** :

**Position 1 : Avant gauche (10 minutes)** :
- □ Pale rotor principale : Fissures, usure, attaches
- □ Verrière : Rayures, microfissures, propreté
- □ Phare atterrissage : Fonctionnement, orientation
- □ Pitot : Obstructions, givrage
- □ Antenne VHF : Fixation, dommages
- □ Pare-brise : État optique, rayures

**Position 2 : Avant droite (5 minutes)** :
- □ Carénage moteur : Fuites huile, signes surchauffe
- □ Filtre à air : Accumulation poussière
- □ Échappement : Fuites, coloration anormale
- □ Batterie : Niveau électrolyte, connexions

**Position 3 : Arrière droite (5 minutes)** :
- □ Rotor de queue : Fissures, extrémités usées
- □ Gouverne direction : Jeu, fixation
- □ Équilibre statique : Masses correctes
- □ Transpondeur antenne : Présence, intégrité

**Position 4 : Arrière gauche (5 minutes)** :
- □ Réservoir carburant : Fuites, jauge
- □ Portes : Verrouillage, fonctionnement
- □ Train d'atterrissage : Pression pneus, état
- □ Éclairage navigation : Fonctionnement

**Position 5 : Dessous (10 minutes)** :
- □ Carter moteur : Fuites huile/carburant
- □ Transmission : État général, fuites
- □ Carénage : Fixation, dommages structurels
- □ Points d'attache : Corrosion, usure

### Vérifications cockpit

**Instruments et équipements (15 minutes)** :
- □ Instruments : Fonctionnement, calibrage
- □ Voyants : Test allumage (master ON)
- □ Fusibles : Présence, continuité
- □ Radio : Test transmission/réception
- □ Transpondeur : Squawk, altitude
- □ Horizon artificiel : Caging, erecting

**Commandes de vol (10 minutes)** :
- □ Collectif : Course complète, verrouillage
- □ Cyclique : Course ±25°, centrage
- □ Pédales : Course symétrique, friction
- □ Trim : Fonctionnement, centrage

**Systèmes fluides (10 minutes)** :
- □ Huile moteur : Niveau, qualité
- □ Carburant : Quantité, qualité, fuites
- □ Freins : Fonctionnement, pression
- □ Pneumatiques : Pression, état

### Tests fonctionnels

**Système électrique** :
- Batterie : Tension >12.5V
- Alternateur : Charge 25-35A sous charge
- Circuits : Test des consommateurs principaux

**Système carburant** :
- Pompe électrique : Pression 0.2-0.3 bar
- Filtres : Aucun signal d'obstruction
- Lignes : Pas de bulles, fuites

**Commandes moteur** :
- Gaz : Course complète, ralenti/idle
- Mélange : Enrichi/appauvri
- Choke : Fonctionnement (si applicable)

## Lecture des documents techniques

La maîtrise des documents techniques constitue une compétence essentielle du pilote moderne.

### Manuel de vol (Flight Manual)

**Structure FAA/EASA** :
- **Section 1** : Généralités (performances, limitations)
- **Section 2** : Urgences (procédures, check-lists)
- **Section 3** : Normal procedures (décollage, atterrissage)
- **Section 4** : Performances (graphiques, calculs)
- **Section 5** : Poids & centrage (enveloppes)
- **Section 6** : Systèmes description (avionique, mécanique)

**Utilisation pratique** :
- Révision avant chaque vol
- Référence pour procédures inhabituelles
- Base pour décisions opérationnelles

### Bulletins de service (Service Bulletins)

**Classification** :
- **Mandatory** : Application obligatoire
- **Recommended** : Application conseillée
- **Optional** : Amélioration non critique

**Suivi** :
- Liste des SB applicables
- Échéanciers respectés
- Modifications documentées

### Instructions de maintenance

**Programme de maintenance** :
- **Inspections 50 heures** : Composants critiques
- **Inspections 100 heures** : Systèmes complets
- **Inspections annuelles** : Conformité générale

**Composants life-limited** :
- **Rotor principal** : 2'200 heures
- **Rotor de queue** : 2'200 heures
- **Transmission** : 2'200 heures
- **Moteur Lycoming** : Selon modèle

### Documentation complémentaire

**Minimum Equipment List (MEL)** :
- Équipements minimaux pour vol
- Procédures en cas de panne
- Autorisations spéciales

**Aircraft Flight Manual Supplement (AFMS)** :
- Modifications approuvées
- Changements de configuration
- Nouvelles procédures

## Journal de vol et carnet de maintenance

Ces documents officiels constituent la mémoire de l'appareil et du pilote.

### Journal de vol pilote

**Informations requises** :
- Date du vol
- Type d'appareil et immatriculation
- Heures de vol (total, jour, nuit)
- Nature du vol (instruction, transport, etc.)
- Lieu décollage/atterrissage
- Conditions météo
- Nom instructeur (si applicable)

**Signature et validation** :
- Signature du pilote
- Validation instructeur si formation
- Horodatage précis

### Carnet de maintenance

**Structure réglementaire** :
- **Page de garde** : Immatriculation, propriétaire
- **Historique** : Modifications, réparations
- **Inspections** : Dates, techniciens
- **Composants** : Heures, cycles, dates pose

**Entrées techniques** :
- Référence bulletin de service
- Description travaux
- Pièces remplacées (P/N, S/N)
- Signature technicien qualifié

### Gestion des heures

**Compteurs Hobbs** :
- Temps moteur total
- Heures de vol effectives
- Base pour maintenance programmée

**Suivi composants** :
- **Calendrier** : Inspections annuelles
- **Heures** : Révisions périodiques
- **Cycles** : Atterrissages pour trains

### Responsabilités du pilote

**Vérifications pré-vol** :
- Inspection visuelle complète
- Fonctionnement systèmes
- Conformité documentation

**Déclarations de pannes** :
- Anomalies découvertes : Note dans journal
- Pannes en vol : Rapport détaillé
- Actions correctives : Suivi résolution

**Archivage** :
- Conservation 5 ans minimum
- Accessibilité immédiate
- Sauvegarde numérique conseillée

## Inspections spécialisées

### Inspection post-vol

**Vérifications systématiques** :
- Niveau huile moteur (ajout si nécessaire)
- État général extérieur
- Anomalies ressenties en vol
- Documentation mise à jour

**Maintenance préventive** :
- Nettoyage général
- Contrôle fixations
- Lubrification points critiques

### Inspections saisonnières

**Saison hivernale** :
- Système dégivrage (si équipé)
- Batterie : Performance froid
- Carburant : Additif antigel
- Pneumatiques : Pression adaptée

**Saison estivale** :
- Refroidissement moteur
- Filtre à air : Nettoyage fréquent
- Pression pneus : Ajustement chaleur
- Carburant : Qualité, évaporation

### Inspections après événements

**Après vol vent fort** :
- Structure : Déformations, fissures
- Rotor : Déséquilibre possible
- Commandes : Jeu accru

**Après atterrissage dur** :
- Train d'atterrissage : Endommagement
- Rotor : Contrôle flapping stops
- Structure fuselage : Intégrité

**Après immersion** :
- Systèmes électriques : Court-circuit
- Huile/carburant : Contamination eau
- Structure : Corrosion accélérée

## Outils de diagnostic pilote

### Équipement de base

**Multimètre numérique** :
- Tension batterie (12-14V normale)
- Continuité circuits électriques
- Test alternateur sous charge

**Jauge de pression** :
- Pneumatiques (2.8 bar froid)
- Huile moteur (2.8-4.1 bar)
- Carburant (si pompe électrique)

**Thermomètre infrarouge** :
- Température échappement
- Points chauds transmission
- Refroidissement moteur

### Analyse de tendances

**Paramètres moteur** :
- Consommation huile (normal <0.5 L/h)
- Températures (tendances anormales)
- Vibrations (augmentation progressive)

**Performances** :
- Vitesse vs puissance (dégradation)
- Temps montée (réduction)
- Autonomie (diminution)

### Diagnostic pannes

**Arbre de décision** :
- Symptôme observé
- Causes probables (liste)
- Tests de confirmation
- Actions correctives

**Exemple : RPM rotor instable** :
1. Vérifier niveau huile
2. Contrôler filtre à air
3. Tester pression huile
4. Inspecter transmission

### Compétences requises

**Connaissances théoriques** :
- Principes maintenance
- Réglementation applicable
- Lecture schémas techniques

**Pratiques** :
- Inspections visuelles
- Tests fonctionnels
- Diagnostic de base

### Formation spécialisée

**Cours maintenance pilote** :
- Identification anomalies
- Procédures inspections
- Documentation correcte

**Qualifications** :
- **Private Pilot** : Inspections de base
- **Commercial Pilot** : Maintenance étendue
- **CFI** : Enseignement procédures

## Synthèse du chapitre

La maintenance et l'inspection constituent le socle de la sécurité du vol hélicoptère. Le pilote, premier responsable de son appareil, doit maîtriser les procédures d'inspection, la lecture des documents techniques et la tenue rigoureuse des carnets de vol et maintenance.

Cette implication directe renforce la relation homme-machine et contribue à la longévité de l'appareil.
