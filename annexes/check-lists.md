# Annexe C – Check-lists imprimables

## Check-list pré-vol extérieur

**Position 1 : Avant gauche**
- [ ] Pales rotor : Fissures, usure, attaches
- [ ] Verrière : Rayures, microfissures, propreté
- [ ] Phare atterrissage : Fonctionnement, orientation
- [ ] Pitot : Obstructions, givrage
- [ ] Antenne VHF : Fixation, dommages
- [ ] Pare-brise : État optique, rayures

**Position 2 : Avant droite**
- [ ] Carénage moteur : Fuites huile, signes surchauffe
- [ ] Filtre à air : Accumulation poussière
- [ ] Échappement : Fuites, coloration anormale
- [ ] Batterie : Niveau électrolyte, connexions

**Position 3 : Arrière droite**
- [ ] Rotor de queue : Fissures, extrémités usées
- [ ] Gouverne direction : Jeu, fixation
- [ ] Équilibre statique : Masses correctes
- [ ] Transpondeur antenne : Présence, intégrité

**Position 4 : Arrière gauche**
- [ ] Réservoir carburant : Fuites, jauge
- [ ] Portes : Verrouillage, fonctionnement
- [ ] Train d'atterrissage : Pression pneus, état
- [ ] Éclairage navigation : Fonctionnement

**Position 5 : Dessous**
- [ ] Carter moteur : Fuites huile/carburant
- [ ] Transmission : État général, fuites
- [ ] Carénage : Fixation, dommages structurels
- [ ] Points d'attache : Corrosion, usure

## Check-list pré-vol cockpit

**Instruments et équipements**
- [ ] Instruments : Fonctionnement, calibrage
- [ ] Voyants : Test allumage (master ON)
- [ ] Fusibles : Présence, continuité
- [ ] Radio : Test transmission/réception
- [ ] Transpondeur : Squawk, altitude
- [ ] Horizon artificiel : Caging, erecting

**Commandes de vol**
- [ ] Collectif : Course complète, verrouillage
- [ ] Cyclique : Course ±25°, centrage
- [ ] Pédales : Course symétrique, friction
- [ ] Trim : Fonctionnement, centrage

**Systèmes fluides**
- [ ] Huile moteur : Niveau, qualité
- [ ] Carburant : Quantité, qualité, fuites
- [ ] Freins : Fonctionnement, pression
- [ ] Pneumatiques : Pression, état

## Check-list démarrage

**Préparation**
- [ ] Portes : Fermées et verrouillées
- [ ] Harnais : Attachés et ajustés
- [ ] Sièges : Réglés et verrouillés
- [ ] Commandes : Libres d'obstruction

**Instruments et équipements**
- [ ] Master switch : OFF
- [ ] Alternateur : OFF
- [ ] Instruments : Testés (pression dynamique)
- [ ] Radio : Fréquence sol + CTAF

**Commandes de vol**
- [ ] Collectif : Bas (verrouillé)
- [ ] Cyclique : Centré et frictionné
- [ ] Pédales : Centrées
- [ ] Trim : Réglé neutre

**Moteur et systèmes**
- [ ] Mélange : RICHE (carburateur froid)
- [ ] Choke : Selon température
- [ ] Pompe carburant : OFF (si équipée)
- [ ] Starter : Test circuit

**Séquence démarrage**
- [ ] Master : ON
- [ ] Alternateur : ON (vérifier charge)
- [ ] Mélange : RICHE
- [ ] Choke : Selon température (<10°C = ON)
- [ ] Starter : Engagement (5-10 sec max)
- [ ] RPM moteur : 800-1'000 tr/min initial
- [ ] Huile : Pression dans les 10 sec
- [ ] Température : Surveillance continue

**Post-démarrage**
- [ ] Instruments : Vérification plages normales
- [ ] Alarmes : Test (RPM bas simulé)
- [ ] Radio : Test transmission

## Check-list avant rotation rotor

**Test commandes**
- [ ] Collectif : Test course (RPM stable)
- [ ] Cyclique : Test course (léger mouvement)
- [ ] Pédales : Test course (mouvement rotor queue)
- [ ] Trim : Ajustement selon conditions

**Systèmes**
- [ ] Alternateur : Charge 25-35A
- [ ] Pression huile : 2.8-4.1 bar
- [ ] Température huile : <80°C
- [ ] Carburant : Quantité et pression

**Communication**
- [ ] Fréquence tour : Réglée
- [ ] Appel roulage : Effectué
- [ ] Clearance : Obtenue

## Check-list décollage

**Avant ligne de vol**
- [ ] Zone décollage : Libre
- [ ] RPM rotor : 500 tr/min (gaz full)
- [ ] Instruments : Verts
- [ ] Altitude : Réglée QNH

**Décollage immédiat**
- [ ] Collectif : Progression douce
- [ ] Attitude : Nez légèrement haut
- [ ] Accélération : >15 kt avant transition
- [ ] RPM rotor : Maintien 500 tr/min

## Check-list croisière

**Paramètres stabilisés**
- [ ] Vitesse : 100-110 kt
- [ ] Altitude : Selon plan de vol
- [ ] RPM rotor : 480-500 tr/min
- [ ] Puissance : 22-24 inHg manifold

**Surveillance continue**
- [ ] Instruments : Vérification périodique
- [ ] Carburant : Consommation normale
- [ ] Températures : Dans plages vertes
- [ ] Trafic : Scan visuel 360°

**Navigation**
- [ ] Position : Selon plan de vol
- [ ] Temps : Estimation vs réel
- [ ] Météo : Changements observés
- [ ] Alternative : Terrain identifié

## Check-list approche

**Préparation approche**
- [ ] Plan d'approche : Défini
- [ ] Vérifications : Effectuées
- [ ] Configuration : RPM rotor 500 tr/min
- [ ] QNH : Réglé destination

**Établissement approche**
- [ ] Vitesse : 60-70 kt
- [ ] Descente : 300-500 ft/min
- [ ] Angle : 3-5° de pente
- [ ] Point arrondi : Identifié

**Arrondi final**
- [ ] Hauteur : 10-15 pieds AGL
- [ ] Collectif : Réduction pour arrondi
- [ ] Cyclique : Redressement attitude
- [ ] Pédales : Tenue cap

## Check-list atterrissage

**Avant atterrissage**
- [ ] Zone : Libre et dégagée
- [ ] Vent : Direction et intensité
- [ ] Terrain : Pente et surface
- [ ] Équipage : Confirmé atterrissage

**Atterrissage stabilisé**
- [ ] Vitesse : Appropriée conditions
- [ ] Descente : Contrôlée
- [ ] Alignement : Précis
- [ ] Toucher : Aussi doux que possible

## Check-list arrêt moteur

**Préparation arrêt**
- [ ] Stationnaire stable
- [ ] Température normale (<100°C)
- [ ] RPM rotor : 500 tr/min
- [ ] Zone : Libre 360°

**Vérifications finales**
- [ ] Équipage : Confirmé arrêt
- [ ] Rotor : Zone dégagée
- [ ] Commandes : Libres
- [ ] Instruments : Normaux

**Séquence arrêt**
- [ ] Mélange : FULL RICH
- [ ] Choke : OFF
- [ ] Alternateur : OFF
- [ ] Ventilateur : Quelques minutes si chaud

**Arrêt rotor**
- [ ] Collectif : Bas progressivement (15-20 sec)
- [ ] RPM rotor : Décroissance contrôlée
- [ ] Moteur : S'arrête automatiquement
- [ ] Rotor : Arrêt complet

**Post-arrêt**
- [ ] Master : OFF
- [ ] Commandes : Verrouiller
- [ ] Harnais : Détacher
- [ ] Inspection : Visuelle rapide

## Check-list urgence - Autorotation

**Reconnaissance**
- [ ] RPM rotor chute <430 tr/min
- [ ] Alarme sonore continue
- [ ] Moteur : Perte puissance audible

**Actions immédiates**
- [ ] Collectif : BAS (entrée autorotation)
- [ ] Cyclique : Avant pour 60-70 kt
- [ ] Pédales : Neutres
- [ ] Gaz : Coupe-feu ON

**Maintien autorotation**
- [ ] Vitesse air : 65 kt optimale
- [ ] Attitude : 15-20° nez bas
- [ ] RPM rotor : 350 tr/min environ
- [ ] Ajustements : Cyclique fin

**Approche finale**
- [ ] Hauteur : 40-60 pieds AGL
- [ ] Vitesse : Maintenir 65 kt
- [ ] Collectif : Préparer récupération
- [ ] Point d'impact : 50-100 m avant

**Récupération**
- [ ] Collectif : Lever fermement
- [ ] Attitude : Redresser progressivement
- [ ] Puissance : Pleins gaz simultané
- [ ] Stabilisation : Stationnaire contrôlé

## Check-list urgence - LTE (Loss of Tail Rotor Effectiveness)

**Reconnaissance**
- [ ] Nez part brusquement (droite généralement)
- [ ] Pédales inopérantes malgré corrections
- [ ] Rotation rapide malgré efforts

**Actions immédiates**
- [ ] Collectif : BAS (réduire puissance)
- [ ] Cyclique : Plein avant (accélérer)
- [ ] Pédales : Contre-rotation maximale
- [ ] Attitude : Nez bas marqué

**Récupération**
- [ ] Accélération >50 kt
- [ ] Puissance réduite progressivement
- [ ] Pédales retrouvent efficacité
- [ ] Stabilisation progressive

## Check-list urgence - Vortex Ring State

**Reconnaissance**
- [ ] Vibrations violentes
- [ ] RPM rotor chute brutalement
- [ ] Contrôle cyclique perdu
- [ ] Descente accélérée

**Actions immédiates**
- [ ] Collectif : BAS complètement
- [ ] Cyclique : Avant pour accélérer
- [ ] Attitude : Nez bas marqué
- [ ] Gaz : Pleins gaz

**Récupération**
- [ ] Accélération >40 kt
- [ ] Puissance réduite
- [ ] Sortie zone vortex
- [ ] RPM rotor récupéré
