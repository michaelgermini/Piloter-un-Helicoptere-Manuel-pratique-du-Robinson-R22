# Chapitre 6 – Préparation avant vol

## Inspection pré-vol détaillée

L'inspection pré-vol constitue le premier rempart contre les pannes et les accidents. Cette vérification systématique du R22 doit être effectuée avec méthode et rigueur.

### Préparation mentale et logistique

**Avant l'approche de l'appareil** :
- Vérifier la météo (METAR/TAF)
- Préparer le plan de vol
- Vérifier les NOTAM (Notices to Airmen)
- Contrôler la validité des licences et qualifications

**Équipement personnel** :
- Manuel de vol R22
- Carte aéronautique appropriée
- Calculateur de vol (E6B)
- Téléphone chargé + fréquence d'urgence

### Inspection extérieure (marche autour)

**Position 1 : Avant gauche** :
- Pale rotor principale : Fissures, erosion, attaches
- Verrière : Rayures, fissures, propreté
- Phare d'atterrissage : Fonctionnement, orientation
- Pitot : Obstructions, givrage possible

**Position 2 : Avant droite** :
- Pare-brise passager : État général
- Antenne VHF : Intégrité, fixation
- Échappement moteur : Fuites, surchauffe
- Filtre à air : Accumulation de poussière

**Position 3 : Arrière droite** :
- Rotor de queue : Fissures, usure des extrémités
- Gouverne de direction : Jeu, fixation
- Équilibrage statique : Poids de balance
- Antenne transpondeur : Présence et fixation

**Position 4 : Arrière gauche** :
- Réservoir carburant : Fuites, jauge
- Portes : Verrouillage, fonctionnement
- Train d'atterrissage : Pression pneus, état
- Éclairage de navigation : Fonctionnement

**Position 5 : Dessous** :
- Carter moteur : Fuites huile
- Transmission : État général, fuites
- Carénage : Fixation, dommages
- Points d'attache : Corrosion, usure

### Inspection intérieure (cockpit)

**Tableau de bord** :
- Instruments : Fonctionnement, étalonnage
- Voyants : Test allumage (master ON)
- Fusibles : Présence, continuité
- Alarmes : Test sonore

**Commandes de vol** :
- Cyclique : Course libre (±25°), friction
- Collectif : Course complète, verrouillage
- Pédales : Course symétrique (±20°)
- Asservissements : Jeu, lubrification

**Sièges et harnais** :
- Réglages : Blocage correct
- Harnais : Boucles, sangles, inertie
- Sièges : Intégrité, confort

### Vérifications fluides et mécanique

**Niveau huile moteur** :
- Jauge : 3.8 L minimum (après vol)
- Aspect : Propre, sans particules
- Quantité : Entre marques min/max

**Carburant** :
- Quantité : Visuel + jauge
- Qualité : Transparent, sans eau
- Type : 100LL uniquement
- Fuites : Aucun signe

**Pneumatiques** :
- Pression : 2.8 bar (41 PSI)
- État : Usure, hernies, coupures
- Roues : Jeu, roulements

**Batterie** :
- Tension : >12.5V (multimètre)
- Electrolyte : Niveau correct
- Connexions : Propres, serrées

## Check-list complète du R22

La check-list structure le déroulement des opérations et prévient les omissions. Elle doit être récitée à voix haute avec le co-pilote.

### Check-list pré-démarrage

**Préparation cockpit** :
- □ Portes : Fermées et verrouillées
- □ Harnais : Attachés et ajustés
- □ Sièges : Réglés et verrouillés
- □ Commandes : Libres de toute obstruction

**Instruments et équipements** :
- □ Master switch : OFF
- □ Alternateur : OFF
- □ Instruments : Testés (pression dynamique)
- □ Radio : Fréquence sol + CTAF

**Commandes de vol** :
- □ Collectif : Bas (verrouillé)
- □ Cyclique : Centré et frictionné
- □ Pédales : Centrées
- □ Trim : Réglé neutre

**Moteur et systèmes** :
- □ Mélange : RICHE (carburateur froid)
- □ Choke : Selon température
- □ Pompe carburant : OFF (si équipée)
- □ Starter : Test circuit

### Check-list démarrage

**Séquence moteur** :
- □ Master : ON
- □ Alternateur : ON (vérifier charge)
- □ Mélange : RICHE
- □ Choke : Selon température (<10°C = ON)

**Démarrage** :
- □ Starter : Engagement (5-10 sec max)
- □ RPM moteur : 800-1'000 tr/min initial
- □ Huile : Pression dans les 10 sec
- □ Température : Surveillance continue

**Post-démarrage** :
- □ Instruments : Vérification plages normales
- □ Alarmes : Test (RPM bas simulé)
- □ Radio : Test transmission

### Check-list avant rotation rotor

**Test commandes** :
- □ Collectif : Test course (RPM stable)
- □ Cyclique : Test course (léger mouvement)
- □ Pédales : Test course (mouvement rotor queue)
- □ Trim : Ajustement selon conditions

**Systèmes** :
- □ Alternateur : Charge 25-35A
- □ Pression huile : 2.8-4.1 bar
- □ Température huile : <80°C
- □ Carburant : Quantité et pression

**Communication** :
- □ Fréquence tour : Réglée
- □ Appel roulage : Effectué
- □ Clearance : Obtenue

### Check-list décollage

**Avant ligne de vol** :
- □ Zone décollage : Libre
- □ RPM rotor : 500 tr/min (gaz full)
- □ Instruments : Verts
- □ Altitude : Réglée QNH

**Décollage immédiat** :
- □ Collectif : Progression douce
- □ Attitude : Nez légèrement haut
- □ Accélération : >15 kt avant transition
- □ RPM rotor : Maintien 500 tr/min

## Lecture des METAR/TAF (météo aéronautique)

La météo constitue le facteur limitant majeur du vol hélicoptère. Sa compréhension précise est essentielle à la sécurité.

### Structure d'un METAR

**En-tête** :
- Indicatif OACI (LFMN = Nice)
- Jour/heure émission (151220Z = 15ème jour, 12:20 UTC)
- Type : METAR (observation) ou SPECI (spécial)

**Conditions météo** :
- Vent : 24015KT = 240° à 15 kt
- Visibilité : 10KM = 10 kilomètres
- Temps présent : TS = orages, GR = grêle
- Nuages : SCT025 = nuages épars à 2'500 ft
- Température/rosée : 25/18 = 25°C air, 18°C point rosée

**Exemple complet** :
```
METAR LFMN 151220Z 24015KT 9999 SCT025 BKN080 25/18 Q1015 NOSIG
```

**Traduction** :
- Aéroport : Nice Côte d'Azur
- Vent : 240° à 15 kt
- Visibilité : 10 km (maximum)
- Nuages : Épars à 2'500 ft, fragmentés à 8'000 ft
- Pression : 1'015 hPa
- Tendance : Pas de changement significatif

### Lecture d'un TAF

**Structure temporelle** :
- Période de validité : 1512/1524 (12h-24h du 15)
- Conditions probables : PROB30 = 30% de probabilité
- Évolution : TEMPO = temporaire, BECMG = becoming

**Exemple TAF** :
```
TAF LFMN 151100Z 1512/1524 24015KT 9999 SCT025
TEMPO 1515/1520 24020G30KT 6000 TS BKN020CB
BECMG 1520/1522 25010KT CAVOK
```

**Analyse** :
- Base : Vent 240° 15 kt, visibilité 10 km, nuages épars 2'500 ft
- Temporaire : 15h-20h, vent fort + orages, visibilité réduite
- Évolution : À partir 20h, vent faible, conditions VFR parfaites

### Application au vol R22

**Limites VFR jour** :
- Visibilité : 5 km minimum
- Distance nuages : 1'500 m horizontal, 300 m vertical
- Plafond : 1'500 ft AGL minimum

**Risques spécifiques hélicoptère** :
- Turbulence : Vent >25 kt, surtout près relief
- Cisaillement : Changements rapides de vent
- Givrage : Température <0°C avec humidité
- Orages : Éviter largement (20 NM minimum)

**Décision météo** :
- Règle 1-2-3 : Visibilité 1 SM, plafond 200 ft, précipitations 3 mm/h
- Facteur hélicoptère : Diviser par 2 les minima avion
- Alternative : Plan B (diversion ou annulation)

## Briefing sécurité

Le briefing sécurité structure la préparation mentale et assure la coordination de l'équipage.

### Briefing pré-vol (5 minutes)

**Météo et conditions** :
- Résumé METAR/TAF
- Conditions attendues en vol
- Plan B météo (diversion, retour)

**Plan de vol** :
- Route et altitudes
- Points de repère
- Temps estimé
- Carburant disponible

**Procédures d'urgence** :
- Autorotation : Point de toucher, procédure
- Panne moteur : Actions immédiates
- Incendie : Évacuation, extincteurs
- Communication : Fréquences urgence

### Coordination équipage

**Rôles définis** :
- Pilote PF (Pilot Flying) : Commandes de vol
- Pilote PM (Pilot Monitoring) : Instruments, navigation
- Alternance : Toutes les 30 minutes

**Signaux standard** :
- "Je prends les commandes" : Changement de pilote
- "Stabilisé" : Paramètres nominaux atteints
- "Go-around" : Abandon approche

**Communication** :
- Phrases courtes et claires
- Confirmation des instructions
- Rappels mutuels des check-lists

### Gestion des facteurs humains

**Fatigue** :
- Sommeil : 8 heures minimum la veille
- Alertness : Auto-évaluation continue
- Limite : Maximum 12 heures de vol/jour

**Stress** :
- Reconnaissance précoce
- Techniques de relaxation
- Décision d'arrêt si nécessaire

**Erreurs communes** :
- Pression temporelle : Ne pas précipiter
- Complaisance : Respecter toujours les procédures
- Communication : Confirmer plutôt que présumer

## Synthèse du chapitre

La préparation avant vol constitue 80% de la sécurité du vol. L'inspection méthodique, l'utilisation rigoureuse des check-lists, l'analyse météorologique précise et le briefing sécurité forment un ensemble cohérent qui prévient la plupart des incidents.

Cette phase demande autant de discipline mentale que de compétence technique, préparant l'esprit autant que la machine au défi du vol.
