# Chapitre 7 – Les premières leçons

## Démarrage et mise en régime rotor

Le démarrage constitue le premier contact physique avec l'hélicoptère. Cette opération, apparemment simple, requiert précision et coordination.

### Préparation au démarrage

**Positionnement** :
- Zone dégagée : 10 m rayon minimum
- Vent arrière : Préféré pour refroidissement
- Équipage prêt : Harnais attachés

**Vérifications finales** :
- Zone arrière libre : Pas de personnel
- Rotor dégagé : Aucune obstruction
- Commandes libres : Collectif verrouillé
- Instruments : Master ON

### Séquence de démarrage

**Phase 1 : Préparation moteur** :
1. Master switch : ON
2. Alternateur : ON (voyant vert)
3. Mélange : RICHE (carburateur froid)
4. Choke : ON si <10°C
5. Pompe carburant : OFF (circuit gravitaire)

**Phase 2 : Engagement starter** :
1. Starter : Appuyer (5 secondes maximum)
2. RPM moteur : 800-1'000 tr/min initial
3. Huile : Pression <10 secondes (alarme si >30 sec)
4. Température : Surveillance continue

**Phase 3 : Réchauffement** :
1. RPM stabilisé : 1'200 tr/min (idle)
2. Choke : OFF progressivement
3. Température huile : <80°C avant rotation rotor
4. Instruments : Vérification plages vertes

> ⚠️ **Attention** : Ne jamais dépasser 30 secondes de starter. Risque de surchauffe batterie et starter.

### Mise en régime rotor

**Préparation rotation** :
- Température huile : 60-80°C
- RPM moteur : Stabilisé
- Zone : Confirmée dégagée
- Équipage : Prêt pour vol

**Séquence rotation** :
1. **Gaz full** : RPM moteur 2'800 tr/min
2. **Collectif** : Lever lentement (10-15 secondes)
3. **RPM rotor** : 500-510 tr/min atteint
4. **Collectif** : Ajuster précision stationnaire

**Temps typiques** :
- Rotation complète : 10-15 secondes
- Stabilisation : 30 secondes
- Test commandes : 1 minute

### Gestion des anomalies

**Démarrage difficile** :
- Choke : Vérifier position
- Batterie : Tester voltage (>12V)
- Carburant : Vérifier quantité et qualité
- Starter : Circuit électrique intact

**Surchauffe** :
- Ventilateur : Vérifier obstruction
- Choke : Retirer progressivement
- RPM : Maintenir idle bas
- Durée : Maximum 2 minutes

**Pression huile manquante** :
- Arrêt immédiat : Procédure d'urgence
- Cause probable : Niveau bas ou pompe défaillante
- Action : Attendre 30 min puis redémarrage

## Apprentissage du stationnaire

Le stationnaire représente l'essence du pilotage hélicoptère. Maîtriser cette attitude exige coordination parfaite et sensibilité.

### Principes fondamentaux

**Équilibre des forces** :
- Portance rotor = Poids appareil
- Poussée queue = Couple moteur
- Résultante verticale = Zéro

**Position idéale** :
- Altitude : 3-5 pieds AGL (effet de sol)
- Attitude : Nez légèrement bas (5-10°)
- Vitesse air : 0 kt (indicatif centré)

### Technique de base

**Coordination commandes** :
1. **Collectif** : Contrôle altitude verticale
2. **Cyclique** : Maintient position latérale
3. **Pédales** : Contrôle direction (cap)

**Sensibilité initiale** :
- Mouvements lents et progressifs
- Corrections anticipées (ne pas attendre dérive)
- Pressions légères sur commandes

### Progression pédagogique

**Niveau 1 : Stabilisation de base** :
- Objectif : Maintenir position ±5 pieds
- Durée : 10-15 secondes continues
- Focus : Coordination collectif/cyclique

**Niveau 2 : Contrôle directionnel** :
- Objectif : Tenue de cap ±10°
- Durée : 30 secondes
- Focus : Pédales et cyclique coordonné

**Niveau 3 : Précision** :
- Objectif : Position centimètre (±1 pied)
- Durée : 1 minute
- Focus : Anticipation et douceur

### Erreurs courantes et corrections

**Ballottement vertical** :
- Cause : Corrections collectif brutales
- Symptôme : "Yo-yo" altitude
- Correction : Mouvements progressifs, regard lointain

**Dérive latérale** :
- Cause : Vent travers ou corrections cyclique insuffisantes
- Symptôme : Translation involontaire
- Correction : Corrections anticipées, référence visuelle

**Rotation nez** :
- Cause : Couple moteur non compensé
- Symptôme : Changement de cap continu
- Correction : Pédales appliquées progressivement

**Excès de corrections** :
- Cause : Stress et précipitation
- Symptôme : Oscillations croissantes
- Correction : Pause, respiration, commandes neutres

> 💡 **Conseil** : "Piloter doucement" - Les hélicoptères pardonnent la lenteur mais punissent la brusquerie.

### Utilisation des repères visuels

**Horizon artificiel** :
- Référence primaire d'attitude
- Confirmation instrumentale du visuel
- Cageable en cas de doute

**Points fixes au sol** :
- Arbre lointain comme référence cap
- Ligne d'horizon pour attitude
- Distance constante pour altitude

**Technique du "fermier"** :
- Regard vers l'avant (cap)
- Vision périphérique (instruments)
- Contrôle continu des paramètres

## Décollage vertical et translation avant

Le décollage combine stationnaire maîtrisé et transition contrôlée vers le vol de croisière.

### Préparation décollage

**Conditions requises** :
- Stationnaire stabilisé 30 secondes
- RPM rotor : 500 tr/min (pleins gaz)
- Instruments : Tous verts
- Zone : Libre sur 90°

**Vérifications finales** :
- Altitude : Réglée QNH départ
- Cap : Orienté vers zone dégagée
- Équipage : Confirmation "prêt"

### Décollage vertical

**Séquence** :
1. **Collectif** : Lever doucement (portance > poids)
2. **Attitude** : Maintenir légèrement nez bas
3. **Altitude** : Monter à 10-15 pieds AGL
4. **Stabilisation** : Confirmer position

**Paramètres critiques** :
- Vitesse ascension : 500 ft/min maximum
- RPM rotor : Maintenir 500 tr/min
- Attitude : Horizon artificiel centré
- Position : Stationnaire parfait

**Durée typique** : 5-8 secondes

### Transition translation

**Accélération progressive** :
1. **Cyclique avant** : Incliner nez (5-10°)
2. **Collectif** : Ajuster selon vitesse
3. **Pédales** : Coordonner pour cap constant
4. **Vitesse** : Atteindre 20-30 kt

**Gestion de la dissymétrie** :
- Compensation cyclique automatique
- Corrections latérales anticipées
- Maintien altitude constant

**Point de décision** :
- Vitesse >15 kt : Engagement irréversible
- RPM rotor : Surveillance continue
- Attitude : Contrôle précis

### Gestion des facteurs externes

**Vent léger (<10 kt)** :
- Décollage dans le vent
- Compensation dérive
- Transition facilitée

**Vent modéré (10-20 kt)** :
- Zone protégée préférée
- Corrections cyclique accrues
- Vigilance dissymétrie

**Pente ou obstacles** :
- Évaluation trajectoire
- Puissance disponible
- Point de rejet défini

## Tenue de cap avec les pédales

La tenue de cap constitue l'un des défis majeurs du pilotage hélicoptère, exigeant coordination et anticipation.

### Principes physiques

**Couple moteur** :
- Force de rotation antihoraire
- Compensation par rotor de queue
- Équilibre dynamique permanent

**Effets secondaires** :
- Changements collectif → variation couple
- Variations vitesse → effet vent relatif
- Inertie rotor → réponse retardée

### Technique de base

**Référence visuelle** :
- Point lointain fixe (horizon)
- Ligne de relief ou route
- Boussole comme confirmation

**Application pédales** :
- Pression légère et continue
- Corrections anticipées
- Coordination avec collectif

### Coordination avancée

**Collectif et pédales** :
- Collectif ↑ → Couple ↑ → Pédales requises
- Collectif ↓ → Couple ↓ → Pédales relâchées
- Timing : Pédales avant collectif

**Vitesse et pédales** :
- Haute vitesse : Compensation accrue
- Basse vitesse : Compensation réduite
- Transition : Ajustement progressif

### Exercices progressifs

**Exercice 1 : Tenue stationnaire** :
- Durée : 1 minute
- Focus : Corrections minimales
- Objectif : Cap ±5° maximum

**Exercice 2 : Translation lente** :
- Vitesse : 10-20 kt
- Durée : 2 minutes
- Focus : Anticipation changements

**Exercice 3 : Changements cap** :
- Manoeuvres : 90° puis 180°
- Précision : ±10°
- Coordination : Toutes commandes

### Erreurs à éviter

**Surcompensation** :
- Cause : Corrections trop importantes
- Effet : Oscillations cap
- Correction : Pressions légères

**Oubli coordination** :
- Cause : Focus sur une commande
- Effet : Dérapage latéral
- Correction : Scan visuel complet

**Fatigue musculaire** :
- Cause : Tension excessive
- Effet : Précision réduite
- Correction : Relâchement périodique

## Synthèse du chapitre

Les premières leçons de pilotage établissent les fondations du vol rotorique. Du démarrage méthodique au stationnaire maîtrisé, chaque étape construit la confiance et la compétence.

La clé du succès réside dans la douceur des mouvements, l'anticipation des corrections et la coordination parfaite des trois commandes. Ces compétences de base formeront la base de tout vol ultérieur.
