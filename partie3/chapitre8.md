# Chapitre 8 – Le vol de croisière

## Maintenir une altitude et une vitesse stables

Le vol de croisière représente la phase la plus longue du vol, exigeant une vigilance continue pour maintenir la stabilité.

### Paramètres de croisière optimaux

**Configuration standard R22** :
- Vitesse : 100-110 kt (185-204 km/h)
- Altitude : 500-1'500 ft AGL (selon relief)
- RPM rotor : 480-500 tr/min
- Puissance : 75-85% (manifold 22-24 inHg)

**Calculs de performance** :
```
Vitesse vraie = Vitesse indiquée × (1 + Altitude/1'000 ft × 0.02)
Exemple : 100 kt à 1'000 ft = 102 kt vrais
```

**Consommation** :
- Puissance 75% : 22 L/h
- Autonomie : 2.5-3.0 heures
- Réserve : 30 minutes (9 L)

### Technique de maintien altitude

**Références primaires** :
- Horizon artificiel : Attitude tangage
- Altimètre : Valeur absolue
- Vario : Tendance verticale
- Visuel : Horizon naturel

**Contrôle précis** :
- Corrections anticipées (ne pas attendre dérive)
- Mouvements cyclique progressifs
- Compensation variations thermiques

### Maintien de vitesse

**Réglage puissance** :
- Vitesse cible : Ajuster collectif
- Compensation : Ouvrir/réduire gaz
- RPM rotor : Maintenir 480-500 tr/min

**Facteurs influençant** :
- Altitude : Densité air diminue
- Température : Performances varient
- Poids : Influence vitesse optimale

**Trim électrique (option)** :
- Réduction effort musculaire
- Maintien automatique attitude
- Ajustement périodique nécessaire

## Virages coordonnés

Les virages constituent une manoeuvre essentielle du pilotage, combinant inclinaison, puissance et coordination.

### Principes aérodynamiques

**Forces en virage** :
- Portance → Composante centrifuge
- Poids → Centre du virage
- Poussée → Direction tangentielle

**Rayon de virage** :
```
R = V² / (g × tan θ)
R : rayon (m), V : vitesse (m/s), θ : angle banc (rad)
```

**Exemple** : V=50 kt (25 m/s), θ=20°
```
R = 625 / (9.81 × 0.36) ≈ 175 m
```

### Technique standard

**Entrée en virage** :
1. **Regard** : Vérifier zone libre
2. **Inclinaison** : Cyclique latéral (15-20°)
3. **Puissance** : Collectif ↑ (maintenir vitesse)
4. **Pédales** : Coordination (virage coordonné)

**Maintien** :
- Inclinaison constante
- Vitesse stable
- Altitude maintenue
- Cap contrôlé

**Sortie** :
1. **Anticipation** : Point de sortie
2. **Redressement** : Cyclique opposé
3. **Puissance** : Ajuster selon besoin
4. **Stabilisation** : Attitude droite

### Virages particuliers

**Virage à 360°** :
- Inclinaison : 15-20° standard
- Temps : 1-2 minutes selon vitesse
- Référence : Point fixe initial

**Virage serré** :
- Inclinaison : 30-45° maximum
- Puissance : Forte augmentation
- Vigilance : G-Force, turbulence

**Virage en montée/descente** :
- Compensation : Puissance accrue/réduite
- Inclinaison : Ajustée selon phase
- Coordination : Maintien vitesse verticale

### Gestion des erreurs

**Virage dérapé** :
- Cause : Pédales insuffisantes
- Symptôme : Glissade latérale
- Correction : Pédales dans le sens du virage

**Perte de vitesse** :
- Cause : Puissance insuffisante
- Symptôme : Décélération
- Correction : Collectif ↑ immédiatement

**Sur-inclinaison** :
- Cause : Excès de correction
- Symptôme : G excessive
- Correction : Redressement progressif

**Perte d'altitude** :
- Cause : Compensation verticale oubliée
- Symptôme : Descente involontaire
- Correction : Cyclique arrière + puissance

> ⚠️ **Attention** : En virage, la charge G peut atteindre 2.0. Prévoir les facteurs physiologiques.

## Navigation de base et repères visuels

La navigation VFR repose sur la combinaison de cartes, de repères visuels et d'estimations temporelles.

### Préparation navigation

**Carte aéronautique** :
- Échelle 1:500'000 (carte VFR Suisse)
- Informations : Relief, obstacles, fréquences
- Repères : Routes, rivières, villes

**Plan de vol** :
- Route : Points de repère principaux
- Altitude : Sécurité + performance
- Temps estimé : Distance/vitesse
- Carburant : +30 min réserve

### Techniques de navigation

**Navigation estimative** :
- Temps écoulé × vitesse = distance parcourue
- Repères visuels comme points de contrôle
- Corrections selon vent effectif

**Navigation par relèvement** :
- Boussole : Cap magnétique
- Repères : Routes, côtes, relief
- Croisement : Plusieurs relèvements

**Navigation temporelle** :
```
Temps estimé = Distance / Vitesse
Exemple : 50 NM à 100 kt = 30 minutes
```

### Repères visuels efficaces

**Éléments linéaires** :
- Routes : Direction claire
- Rivières : Suivi facile
- Voies ferrées : Peu utilisées mais fiables

**Éléments ponctuels** :
- Châteaux d'eau : Visibles de loin
- Églises : Points de repère locaux
- Carrefours : Confirmations position

**Éléments de surface** :
- Lacs : Formes caractéristiques
- Forêts : Bordures nettes
- Champs : Couleurs saisonnières

### Gestion du vent

**Vent prévu vs effectif** :
- Calcul dérive : (Vent ⊥ × temps) / 60
- Correction cap : Arc de cercle
- Vérification : Position réelle vs estimée

**Ajustements en vol** :
- Repère perdu : Cercle pour reconnaissance
- Vent arrière : Gain de temps
- Vent de face : Perte de temps

### Procédures perdu

**Reconnaissance** :
1. Cercle à 360° (2-3 minutes)
2. Identification éléments remarquables
3. Calcul position approximative

**Actions immédiates** :
- Altitude : Monter à sécurité (1'500 ft AGL min)
- Vitesse : Réduire pour meilleure visibilité
- Radio : Contacter ATC ou fréquence d'urgence

**Plan de secours** :
- Retour sur route connue
- Diriger vers relief dégagé
- Préparer atterrissage d'urgence

## Gestion de l'énergie et optimisation

### Surveillance continue

**Paramètres moteurs** :
- RPM rotor : 480-500 tr/min
- Température huile : 80-100°C
- Pression huile : 2.8-4.1 bar
- Carburant : Consommation régulière

**Performance appareil** :
- Vitesse : ±5 kt de cible
- Altitude : ±100 ft
- Attitude : Horizon centré

### Optimisation consommation

**Réglage finesse** :
- Puissance minimale pour vitesse cible
- Altitude optimale selon conditions
- Trim correct pour réduire efforts

**Gestion carburant** :
- Réserve 30 min : Toujours respecter
- Consommation : Noter tendances
- Plan B : Terrain alternatif identifié

### Vigilance environnementale

**Trafic aérien** :
- Scan visuel : 360° régulier
- TCAS/FLARM : Si équipé
- Fréquences : Surveillance CTAF

**Conditions météo** :
- Changements : Nuages, vent, visibilité
- Prévision : Comparer avec TAF
- Décision : Plan B prêt

**Terrain** :
- Relief : Clearance verticale
- Obstacles : Identification précoce
- Zones dégagées : Mémorisées

## Synthèse du chapitre

Le vol de croisière exige une stabilité mentale autant que technique. Maintenir altitude et vitesse stables, exécuter des virages coordonnés et naviguer efficacement forment les compétences essentielles du pilote croisière.

Cette phase, apparemment monotone, demande une vigilance de tous les instants et une anticipation permanente des changements de conditions.
