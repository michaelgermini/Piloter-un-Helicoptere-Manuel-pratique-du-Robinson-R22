# Chapitre 9 – Approche et atterrissage

## Plan d'approche et arrondi

L'approche représente la phase critique du vol où précision et douceur sont essentielles à la sécurité.

### Préparation approche

**Évaluation conditions** :
- Vent : Direction, intensité, variations
- Terrain : Pente, surface, obstacles
- Longueur disponible : Sécurité atterrissage

**Configuration avion** :
- RPM rotor : 500 tr/min (pleins gaz)
- Altitude : QNH correctement réglé
- Instruments : Vérification fonctionnement

**Plan d'approche** :
- Angle : 3-5° de descente
- Vitesse : 60-70 kt (approche)
- Point d'arrondi : 10-15 pieds AGL

### Technique d'approche

**Phase d'approche** :
1. **Réduction vitesse** : Cyclique arrière progressivement
2. **Descente** : Collectif bas pour descente
3. **Alignement** : Cyclique latéral pour trajectoire
4. **Stabilisation** : Paramètres constants

**Paramètres d'approche** :
- Vitesse : 60 kt (110 km/h)
- Descente : 300-500 ft/min
- Angle : Visuel sur point d'atterrissage
- RPM rotor : Maintien 500 tr/min

**Références visuelles** :
- Point d'impact : Ligne d'horizon
- Trajectoire : Piste imaginaire
- Obstacles : Clearance verticale

### Manoeuvre d'arrondi

**Timing** :
- Hauteur : 10-15 pieds AGL
- Distance : 50-100 m du point cible
- Vitesse : 50-60 kt

**Séquence arrondi** :
1. **Collectif** : Lever pour réduire descente
2. **Cyclique arrière** : Redresser attitude
3. **Pédales** : Ajuster cap final
4. **Collectif** : Contrôle douceur atterrissage

**Transition stationnaire** :
- Vitesse → 0 kt
- Altitude stabilisée
- Position parfaite

## Effet de sol et descente maîtrisée

L'effet de sol influence significativement les dernières secondes du vol.

### Compréhension effet de sol

**Principe physique** :
- Air comprimé sous rotor
- Réduction vitesse induite (Vi ↓)
- Augmentation portance (10-20%)

**Zone d'influence** :
- Hauteur efficace : Rayon rotor (3.8 m)
- Maximum à h = 0.5 × rayon
- Progressif jusqu'à 2 × rayon

**Impact opérationnel** :
- Puissance requise ↓ en approche
- Flottement possible près sol
- Atterrissage plus doux

### Gestion en descente

**Approche avec effet de sol** :
- Puissance réduite progressivement
- Vitesse stabilisée par cyclique
- Anticipation du "cushion"

**Évitement du flottement** :
- Ne pas "chasser" l'atterrissage
- Maintenir approche stabilisée
- Collectif bas si nécessaire

**Technique anti-flottement** :
- Approche légèrement haute
- Arrondi ferme mais progressif
- Collectif constant pendant arrondi

### Facteurs environnementaux

**Vent arrière** :
- Effet de sol accru
- Risque flottement élevé
- Approche plus haute

**Vent de face** :
- Effet de sol réduit
- Atterrissage plus ferme
- Puissance supplémentaire requise

**Terrain incliné** :
- Effet de sol asymétrique
- Corrections cyclique accrues
- Vigilance roulis

## Check-list d'arrêt moteur

L'arrêt moteur doit être exécuté avec méthode pour assurer la sécurité et la longévité du moteur.

### Préparation arrêt

**Conditions requises** :
- Stationnaire stable
- Température normale (<100°C)
- RPM rotor : 500 tr/min
- Zone dégagée

**Vérifications finales** :
- Équipage : Confirmé arrêt
- Rotor : Zone libre 360°
- Commandes : Libres

### Séquence d'arrêt

**Phase 1 : Préparation** :
1. **Mélange** : FULL RICH (carburant résiduel)
2. **Choke** : OFF
3. **Alternateur** : OFF (si conditions normales)
4. **Ventilation** : Quelques minutes si chaud

**Phase 2 : Arrêt rotor** :
1. **Collectif** : Bas progressivement (15-20 sec)
2. **RPM rotor** : Décroissance contrôlée
3. **Moteur** : S'arrête automatiquement
4. **Rotor** : Continuer jusqu'arrêt complet

**Phase 3 : Post-arrêt** :
1. **Master** : OFF
2. **Commandes** : Verrouiller
3. **Harnais** : Détacher
4. **Inspection** : Visuelle rapide

### Gestion anomalies

**Moteur cale brusquement** :
- Cause : Carburant insuffisant
- Action : Redémarrage immédiat si possible
- Sécurité : Rotor tournant, rester à bord

**Surchauffe** :
- Ventilation prolongée (5-10 min)
- Cause : Refroidissement insuffisant
- Prévention : Arrêt dans vent frais

**Rotor ne s'arrête pas** :
- Collectif bas complètement
- Friction rotor de queue
- Sécurité : Ne pas approcher

## Techniques d'atterrissage spéciales

### Atterrissage vent fort

**Vent de face (>15 kt)** :
- Approche plus haute
- Arrondi plus ferme
- Puissance disponible

**Vent arrière (<10 kt)** :
- Approche basse
- Utilisation effet de sol
- Vigilance flottement

**Vent travers** :
- Approche crabe (cyclique compensé)
- Transition finale dans le vent
- Pédales pour tenue cap

### Atterrissage sur pente

**Pente montante** :
- Approche haute
- Atterrissage nez haut
- Puissance réduite tard

**Pente descendante** :
- Approche basse
- Atterrissage nez bas
- Contrôle descente

### Atterrissage sur surface meuble

**Herbe haute** :
- Vitesse réduite
- Atterrissage ferme
- Pas de flottement

**Neige/sol mou** :
- Patins conseillés
- Atterrissage léger
- Éviter rebond

## Sécurité et facteurs humains

### Gestion du stress

**Pression temporelle** :
- Approche stabilisée
- Pas d'accélération finale
- Confiance en ses capacités

**Fatigue** :
- Reconnaissance précoce
- Simplification procédures
- Arrêt si nécessaire

### Erreurs communes

**Approche trop basse** :
- Cause : Sous-estimation effet de sol
- Conséquence : Atterrissage dur
- Prévention : Approche visuelle haute

**Arrondi tardif** :
- Cause : Timing incorrect
- Conséquence : Arrivée rapide
- Prévention : Point d'arrondi défini

**Corrections de dernière minute** :
- Cause : Stress, précipitation
- Conséquence : Perte contrôle
- Prévention : Approche stabilisée

## Synthèse du chapitre

L'approche et l'atterrissage constituent le point culminant du vol, où toutes les compétences acquises se conjuguent. Le plan d'approche méthodique, la gestion de l'effet de sol et l'arrêt moteur rigoureux assurent des opérations sûres et répétables.

Cette phase exige autant de préparation mentale que technique, transformant la complexité apparente en séquence maîtrisée.
