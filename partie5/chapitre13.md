# Chapitre 13 – Exercices pratiques

## Maintenir un stationnaire (exercice de précision)

Le stationnaire maîtrisé constitue la base de toutes les manoeuvres en hélicoptère. Cet exercice développe la coordination fine et la stabilité.

### Objectifs pédagogiques

**Compétences développées** :
- Coordination parfaite collectif/cyclique/pédales
- Maintien altitude ±2 pieds
- Tenue de cap ±5°
- Gestion des corrections anticipées

**Durée recommandée** : 3-5 minutes par session
**Altitude** : 3-5 pieds AGL (effet de sol)
**Conditions** : Vent <10 kt, visibilité claire

### Technique de base

**Position idéale** :
- Altitude constante (référence sol)
- Attitude droite (horizon artificiel centré)
- Cap maintenu (point fixe lointain)
- Position latérale stable

**Références visuelles** :
- **Primaire** : Ligne d'horizon naturel
- **Secondaire** : Point fixe au sol (arbre, bâtiment)
- **Tertiaire** : Instruments de confirmation

**Contrôle fin** :
- Corrections légères et progressives
- Anticipation des dérives
- Pressions constantes minimales

### Progression pédagogique

**Niveau 1 : Stabilisation (1 minute)** :
- Focus : Atteindre et maintenir position
- Tolérance : ±5 pieds altitude, ±10° cap
- Succès : Position stable 30 secondes continues

**Niveau 2 : Précision (2 minutes)** :
- Focus : Réduire tolérances
- Tolérance : ±2 pieds altitude, ±5° cap
- Succès : Contrôle précis 1 minute

**Niveau 3 : Endurance (3-5 minutes)** :
- Focus : Maintenir concentration
- Tolérance : ±1 pied altitude, ±2° cap
- Succès : Session complète sans perte contrôle

### Erreurs courantes et corrections

**Ballottement vertical** :
- **Cause** : Corrections collectif trop importantes
- **Symptôme** : "Yo-yo" altitude
- **Correction** : Mouvements progressifs, regard lointain

**Dérive latérale** :
- **Cause** : Vent ou corrections cyclique insuffisantes
- **Symptôme** : Translation involontaire
- **Correction** : Corrections anticipées, référence fixe

**Variations cap** :
- **Cause** : Pédales non coordonnées
- **Symptôme** : Rotation lente nez
- **Correction** : Pressions pédales légères continues

### Variantes avancées

**Stationnaire décentré** :
- Position : 10-20 pieds d'un point fixe
- Challenge : Gestion dissymétrie visuelle
- Objectif : Maintien relatif précis

**Stationnaire yeux fermés** :
- Références : Instruments uniquement
- Challenge : Dépendance instruments
- Objectif : Maîtrise cockpit

**Stationnaire vent léger** :
- Conditions : 5-10 kt travers
- Challenge : Corrections continues
- Objectif : Anticipation météo

## Passage en translation

La transition stationnaire-croisière constitue une manoeuvre critique exigeant timing et coordination parfaits.

### Principes de transition

**Accélération contrôlée** :
- Vitesse progressive 0 → 60 kt
- Puissance adaptée (RPM constant)
- Attitude maintenue initialement

**Gestion dissymétrie** :
- Compensation cyclique automatique
- Corrections latérales anticipées
- Maintien altitude constant

**Point de décision** :
- Vitesse >15 kt : Engagement irréversible
- RPM rotor : Surveillance continue
- Attitude : Contrôle précis

### Technique standard

**Préparation** :
1. **Vérifications** : Zone dégagée 360°, paramètres normaux
2. **Position** : Stationnaire stabilisé
3. **Cap** : Orienté vers zone de transition

**Séquence** :
1. **Cyclique avant** : 5-10° pour accélération
2. **Collectif** : Ajuster puissance selon vitesse
3. **Pédales** : Coordination cap constant
4. **Vitesse** : Atteindre 60-70 kt progressivement

**Stabilisation croisière** :
- Vitesse cible atteinte
- Altitude constante
- Paramètres normaux
- Trim ajusté

### Exercices progressifs

**Transition basic** :
- Distance : 200-300 m
- Vitesse finale : 60 kt
- Focus : Coordination douce
- Répétitions : 5-10 par session

**Transition précise** :
- Altitude maintenue ±10 pieds
- Cap maintenu ±5°
- Durée : 30-45 secondes
- Focus : Stabilité parfaite

**Transition rapide** :
- Accélération : 20 kt en 10 secondes
- Challenge : Gestion couple/G
- Objectif : Manoeuvre dynamique

### Gestion des facteurs externes

**Vent de face** :
- Transition facilitée
- Puissance réduite
- Vigilance décélération

**Vent arrière** :
- Résistance accrue
- Puissance supplémentaire
- Vigilance LTE possible

**Terrain incliné** :
- Effet de sol asymétrique
- Corrections cyclique accrues
- Vigilance roulis

## Montée, descente, virages coordonnés

Ces manoeuvres fondamentales développent le contrôle tridimensionnel de l'hélicoptère.

### Montée verticale

**Technique** :
- Collectif : Lever progressif
- Attitude : Nez légèrement haut (5-10°)
- Vitesse : 40-60 kt selon puissance
- RPM rotor : Maintenir 500 tr/min

**Paramètres** :
- Taux montée : 500 ft/min maximum
- Accélération : Douce, progressive
- Coordination : Pédales anticipées

**Exercice** :
- Altitude : 200-500 pieds gain
- Précision : ±20 pieds cible
- Durée : 1-2 minutes

### Descente contrôlée

**Technique** :
- Collectif : Bas progressif
- Attitude : Nez bas (10-15°)
- Vitesse : 60-80 kt
- RPM rotor : Maintenir 500 tr/min

**Prévention vortex ring** :
- Vitesse minimum 50 kt
- Descente maximum 500 ft/min
- Puissance adaptée

**Exercice** :
- Altitude : 500-200 pieds perte
- Précision : Arrêt précis altitude
- Durée : 1-2 minutes

### Virages coordonnés

**Entrée** :
1. **Regard** : Vérifier zone libre
2. **Inclinaison** : Cyclique latéral (15-20°)
3. **Puissance** : Collectif ↑ pour maintenir vitesse
4. **Pédales** : Coordination virage coordonné

**Maintien** :
- Inclinaison constante
- Vitesse stable
- Altitude maintenue
- Rayon constant

**Sortie** :
1. **Anticipation** : Point de sortie
2. **Redressement** : Cyclique opposé
3. **Puissance** : Ajuster
4. **Stabilisation** : Attitude droite

**Exercices variés** :
- **Virage standard** : 360°, 15-20° inclinaison
- **Virage serré** : 45° max, haute puissance
- **Virage en montée/descente** : Combinaisons complexes

### Coordination avancée

**Manoeuvres combinées** :
- Montée + virage = Spirale
- Descente + virage = Approche circulaire
- Accélération + virage = Manoeuvre dynamique

**Précision** :
- Altitude : ±10 pieds
- Cap : ±5°
- Vitesse : ±5 kt
- Durée : Sessions 10-15 minutes

## Simulation d'autorotation

L'autorotation simulée constitue l'entraînement essentiel à la procédure d'urgence.

### Préparation mentale

**Rappel principes** :
- Rotor tournant par vent relatif
- Pas collectif réduit
- Vitesse descente contrôlée
- Énergie stockée

**Configuration simulateur** :
- Hauteur sécurité : 500-1'000 pieds AGL
- Zone dégagée : Terrain plat adapté
- Conditions : Vent léger, visibilité claire

### Séquence simulée

**Déclenchement** :
- Pleins gaz initialement
- Collectif bas brusquement (simulation panne)
- Attitude : Neutre initialement

**Phase entrée** :
- Vitesse air : Maintenir 60-70 kt
- Attitude : 15-20° nez bas
- RPM rotor : Décroissance contrôlée
- Stabilisation : Paramètres constants

**Phase approche** :
- Hauteur : 40-60 pieds AGL
- Vitesse : Maintenir 65 kt optimale
- Collectif : Préparer récupération
- Point d'impact : 50-100 m avant

**Phase récupération** :
- Collectif : Lever fermement
- Attitude : Redresser progressivement
- Puissance : Pleins gaz simultané
- Stabilisation : Stationnaire contrôlé

### Exercices progressifs

**Autorotation basic** :
- Hauteur : 500 pieds
- Focus : Séquence correcte
- Répétitions : 5-10 par session

**Autorotation précise** :
- Hauteur variable : 300-800 pieds
- Focus : Timing récupération
- Objectif : Toucher doux

**Autorotation avancé** :
- Conditions : Vent, turbulence
- Challenge : Variables externes
- Objectif : Maîtrise totale

### Analyse post-vol

**Débriefing structuré** :
- **Timing** : Délais critiques respectés ?
- **Technique** : Séquence correcte ?
- **Précision** : Paramètres optimaux ?
- **Erreurs** : Points d'amélioration

**Métriques performance** :
- Altitude perte : Minimum 100 pieds
- RPM rotor : 350-400 tr/min maintenu
- Point d'impact : Précision ±20 m
- Toucher : Douceur évaluée

### Transfert vol réel

**Différences simulateur** :
- Forces G absentes
- Vibrations réduites
- Stress moindre

**Préparation réelle** :
- Sessions simulateur régulières
- Visualisation procédures
- Confiance technique acquise

**Progression sécurisée** :
- Autorotation basse altitude d'abord
- Hauteurs croissantes progressivement
- Validation instructeur systématique

## Intégration et progression

### Programme structuré

**Semaine 1-2 : Bases** :
- Stationnaire précision
- Transitions simples
- Montées/descentes isolées

**Semaine 3-4 : Coordination** :
- Manoeuvres combinées
- Virages en montée/descente
- Autorotation basic

**Semaine 5+ : Maîtrise** :
- Conditions dégradées
- Urgences complexes
- Scénarios opérationnels

### Évaluation continue

**Auto-évaluation** :
- Journal de vol détaillé
- Points forts/faibles identifiés
- Objectifs personnels définis

**Feedback instructeur** :
- Sessions débriefing
- Corrections techniques
- Encouragement motivation

### Maintenance compétences

**Fréquence recommandée** :
- Sessions hebdomadaires minimum
- Focus rotationnel sur faiblesses
- Progression mesurée

**Diversité exercices** :
- Conditions météo variées
- Terrains différents
- Heures jour/nuit

## Synthèse du chapitre

Les exercices pratiques constituent le laboratoire où théorie et compétences se transforment en automatismes. Du stationnaire de précision aux autorotations simulées, chaque manoeuvre renforce la confiance et la sécurité du pilote.

Cette progression structurée, combinée au simulateur, offre une formation complète et efficace pour maîtriser le Robinson R22.
