# Chapitre 11 – Sécurité du vol

## Facteurs humains et erreurs courantes

La sécurité du vol hélicoptère dépend autant des facteurs techniques que des aspects humains. Les erreurs de pilotage représentent la première cause d'accidents.

### Les facteurs humains majeurs

**Fatigue et vigilance** :
- **Sommeil insuffisant** : Réduction performance de 30%
- **Rythme circadien** : Risque accru 02h-06h
- **Charge mentale** : Surcharge cognitive

**Stress et pression** :
- **Pression temporelle** : Précipitation dangereuse
- **Pression sociale** : Résister aux pairs
- **Stress personnel** : Problèmes externes

**Complaisance** :
- **Routines** : Omission procédures
- **Expérience** : Surestimation compétences
- **Familiarité** : Baisse vigilance

### Erreurs courantes en formation

**Stationnaire et décollage** :
- Corrections trop brutales
- Oubli coordination pédales
- Décollage prématuré

**Vol de croisière** :
- Navigation approximative
- Surveillance instruments insuffisante
- Gestion carburant négligée

**Approche et atterrissage** :
- Arrondi tardif
- Gestion effet de sol incorrecte
- Atterrissage vent arrière risqué

### Gestion des erreurs

**Détection précoce** :
- Signes physiques : Sueurs, tension
- Signes comportementaux : Précipitation
- Signes situationnels : Paramètres dégradés

**Stratégies de récupération** :
- Pause mentale : Respirer profondément
- Simplification : Focuser sur essentiel
- Aide extérieure : Consulter instructeur

**Culture de sécurité** :
- Rapport volontaire des erreurs
- Analyse sans jugement
- Amélioration continue

## Gestion du stress et de la charge mentale

Le pilotage hélicoptère impose une charge mentale importante qu'il faut gérer efficacement.

### Sources de stress

**Technique** :
- Complexité des manoeuvres
- Précision requise
- Conditions météo dégradées

**Environnemental** :
- Trafic aérien dense
- Espace aérien complexe
- Contraintes temporelles

**Personnel** :
- Responsabilité vies humaines
- Pression performance
- Fatigue accumulée

### Techniques de gestion

**Préparation mentale** :
- Visualisation positive
- Routines stabilisantes
- Affirmations constructives

**En vol** :
- Respiration contrôlée
- Scan visuel structuré
- Priorisation des tâches

**Récupération** :
- Débriefing post-vol
- Activités relaxantes
- Sommeil de qualité

### Charge mentale optimale

**Sous-charge** :
- Risque : Inattention, ennui
- Symptômes : Distraction, erreurs d'inattention
- Gestion : Augmenter vigilance

**Charge optimale** :
- État : Concentré, efficace
- Performance : Maximale
- Maintien : Routines régulières

**Surcharge** :
- Symptômes : Confusion, précipitation
- Erreurs : Omission, timing incorrect
- Gestion : Simplifier, déléguer

## Décision du pilote (PDM)

La décision du pilote constitue le processus rationnel de prise de décision en situation complexe.

### Processus PDM

**1. Reconnaissance situation** :
- Faits objectifs identifiés
- Options disponibles évaluées
- Risques quantifiés

**2. Évaluation risques** :
- Probabilité d'occurrence
- Sévérité conséquences
- Facteurs aggravants

**3. Génération options** :
- Solutions immédiates
- Alternatives de repli
- Stratégies préventives

**4. Choix optimal** :
- Avantages/inconvénients pesés
- Facteurs humains considérés
- Décision justifiée

**5. Mise en oeuvre** :
- Plan d'action clair
- Ressources coordonnées
- Monitoring continu

### Outils PDM

**Matrices décisionnelles** :
```
Situation : Météo marginale
Option 1 : Continuer → Risque élevé, gain temps
Option 2 : Divertir → Risque faible, perte temps
Option 3 : Annuler → Risque nul, retour base
```

**Règles mnémoniques** :
- **PACE** : Piloter, Analyser, Coordonner, Exécuter
- **DECIDE** : Détecter, Estimer, Choisir, Identifier, Faire, Évaluer

**Check-lists mentales** :
- Conditions météo
- Performances appareil
- Qualifications équipage
- Ressources disponibles

### Exemples pratiques

**Météo dégradée en vol** :
- Reconnaissance : Visibilité réduite, plafond bas
- Évaluation : VFR impossible, IFR non qualifié
- Options : Divertir maintenant vs continuer
- Décision : Divertir vers terrain dégagé

**Panne mineure** :
- Reconnaissance : RPM fluctuant, pas critique
- Évaluation : Atterrissage possible, pas d'urgence
- Options : Continuer vs atterrir immédiatement
- Décision : Atterrir prochain terrain adapté

## Limites personnelles et météo

Chaque pilote doit connaître et respecter ses limites personnelles et celles imposées par la météo.

### Limites personnelles

**Physiques** :
- Vision : 1.0 minimum, correction acceptée
- Santé : Visite médicale régulière
- Fatigue : Limite 12h vol/jour, 8h veille
- Médicaments : Effets secondaires connus

**Techniques** :
- Qualifications : Valides et à jour
- Expérience : Heures récentes suffisantes
- Monotype : Pas de transition brusque
- Conditions : Rester dans enveloppe connue

**Psychologiques** :
- Stress : Reconnaître signes personnels
- Confiance : Ni surestimation ni doute excessif
- Motivation : Voler pour bonnes raisons

### Limites météorologiques

**VFR minimums** :
- Visibilité : 5 km jour, 8 km nuit
- Distance nuages : 1'500 m horizontal, 300 m vertical
- Plafond : 1'500 ft AGL minimum

**Facteurs aggravants** :
- Turbulence : Éviter modérée-sévère
- Givrage : Température <0°C + humidité
- Orages : 20 NM minimum
- Vent : Selon type manoeuvre

### Gestion des minima personnels

**Établissement** :
- Expérience accumulée
- Incidents passés analysés
- Conseils instructeurs
- Évolution progressive

**Ajustement dynamique** :
- Conditions actuelles
- État physique/mental
- Complexité mission
- Ressources disponibles

### Culture "non" sécurisée

**Pression sociale** :
- Résister aux demandes externes
- Priorité sécurité absolue
- Communication assertive

**Exemples de refus** :
- "Non, visibilité insuffisante"
- "Non, trop fatigué aujourd'hui"
- "Non, conditions hors mes limites"

**Alternatives positives** :
- Proposer report
- Suggérer alternative
- Expliquer rationnellement

## Synthèse du chapitre

La sécurité du vol hélicoptère repose sur la maîtrise des facteurs humains autant que techniques. La gestion du stress, la prise de décision rationnelle et le respect des limites personnelles forment les piliers d'une sécurité durable.

Cette approche transforme les risques potentiels en opportunités de succès, faisant du pilote un professionnel conscient et responsable.
