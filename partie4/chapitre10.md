# Chapitre 10 – Gestion des pannes

## Autorotation et panne moteur

L'autorotation constitue la procédure d'urgence fondamentale du pilotage hélicoptère, permettant un atterrissage contrôlé sans puissance moteur.

### Principes de l'autorotation

**Mécanisme physique** :
- Rotor tournant par vent relatif
- Pas collectif réduit (autorotation)
- Vitesse de descente contrôlée
- Énergie stockée dans rotor

**Phases de l'autorotation** :
1. **Entrée** : Perte puissance → Autorotation
2. **Maintien** : Vitesse descente optimale
3. **Arrondi** : Récupération énergie
4. **Atterrissage** : Toucher doux

**Paramètres critiques** :
- Vitesse air : 60-70 kt (110-130 km/h)
- RPM rotor : 300-400 tr/min (autorotation)
- Descente : 1'500-2'000 ft/min
- Distance parcourue : 1-2 NM par 1'000 ft

### Procédure d'autorotation

**Reconnaissance panne** :
- RPM rotor chute <430 tr/min
- Alarme sonore continue
- Moteur : Perte puissance audible

**Actions immédiates** :
1. **Collectif** : BAS (entrée autorotation)
2. **Cyclique** : Avant pour 60-70 kt
3. **Pédales** : Neutres
4. **Gaz** : Coupe-feu ON

**Maintien autorotation** :
- Vitesse : 65 kt optimale
- Attitude : 15-20° nez bas
- RPM rotor : 350 tr/min environ
- Ajustements : Cyclique fin

**Approche finale** :
- Hauteur : 40-60 pieds AGL
- Vitesse : Maintenir 65 kt
- Collectif : Lever progressivement (récupération)
- Cyclique : Redresser pour arrondi

**Atterrissage** :
- Point d'impact : 50-100 m avant
- Collectif : Plein haut en douceur
- Attitude : Nez haut modéré
- Toucher : Aussi doux que possible

### Facteurs de succès

**Altitude disponible** :
- >1'000 ft : Autorotation complète possible
- 500-1'000 ft : Autorotation partielle
- <500 ft : Peu de marge de manoeuvre

**Vitesse initiale** :
- Haute altitude : Plus de temps pour établir
- Basse altitude : Autorotation immédiate
- Croisière : Conditions optimales

**Terrain d'atterrissage** :
- Préféré : Surface plane, dégagée
- Acceptable : Pente douce, herbe
- Éviter : Eau, obstacles, pente raide

### Entraînement et pratique

**Simulation au sol** :
- Procédure mentale répétée
- Points de repère mémorisés
- Temps de réaction mesuré

**Exercices en vol** :
- Autorotation puissance (simulation)
- Récupération basse altitude
- Variations de hauteur entrée

**Fréquence recommandée** :
- Tous les 6 mois minimum
- Après changement instructeur
- Avant qualification solo

## Perte d'efficacité du rotor de queue (LTE)

La perte d'efficacité du rotor de queue (Loss of Tail Rotor Effectiveness - LTE) représente une urgence majeure pouvant mener à la perte de contrôle.

### Mécanismes de la LTE

**Causes principales** :
- Vent arrière >15 kt en vol lent
- Turbulence dans sillage
- Manoeuvres brusques en basse vitesse
- Défaut mécanique rotor queue

**Conditions favorisantes** :
- Vitesse air <30 kt
- Puissance élevée
- Vent arrière relatif
- Haute altitude densité

**Symptômes** :
- Nez part brusquement (généralement droite)
- Commandes pédales inopérantes
- Rotation rapide malgré corrections
- Vibrations accrues

### Procédure de récupération LTE

**Reconnaissance** :
- Rotation nez inattendue
- Pédales sans effet
- Vitesse chute rapidement

**Actions immédiates** :
1. **Collectif** : BAS (réduire puissance)
2. **Cyclique** : Plein avant (accélérer)
3. **Pédales** : Contre-rotation maximale
4. **Attitude** : Nez bas accentué

**Récupération** :
- Accélération >50 kt
- Puissance réduite progressivement
- Pédales retrouvent efficacité
- Stabilisation progressive

**Temps critique** :
- Action <2 secondes : Succès probable
- 2-5 secondes : Récupération possible
- >5 secondes : Contrôle perdu probable

### Prévention LTE

**Techniques opérationnelles** :
- Éviter vol lent vent arrière
- Transitions rapides (>15 kt)
- Manoeuvres douces
- Vigilance en turbulence

**Limites de vent** :
- Stationnaire : 24 kt maximum
- Translation lente : 17 kt travers
- Croisière : 35 kt travers maximum

**Formation** :
- Reconnaissance symptômes
- Procédures automatiques
- Entraînement simulateur

## Vortex ring state et prévention

Le vortex ring state (état de vortex) survient lorsque l'hélicoptère descend dans son propre sillage de descente.

### Physique du phénomène

**Formation des vortex** :
- Air descendant du rotor
- Création tourbillons concentriques
- Rotor "nage" dans air turbulent

**Conditions de survenue** :
- Descente rapide (>500 ft/min)
- Vitesse basse (<30 kt)
- Puissance élevée (collectif haut)
- Haute altitude densité

**Symptômes** :
- Vibrations violentes
- Chute RPM rotor brutale
- Contrôle cyclique perdu
- Descente accélérée

### Récupération

**Actions immédiates** :
1. **Collectif** : BAS complètement
2. **Cyclique** : Avant pour accélérer
3. **Attitude** : Nez bas marqué
4. **Gaz** : Pleins gaz

**Récupération** :
- Accélération >40 kt
- Puissance réduite
- Sortie zone vortex
- RPM rotor récupéré

**Temps de récupération** :
- 2-5 secondes pour sortie zone
- 10-15 secondes récupération complète
- Altitude perdue : 100-300 ft

### Prévention

**Techniques de descente** :
- Vitesse minimum 50 kt
- Descente <500 ft/min
- Puissance adaptée vitesse
- Éviter collectif haut + basse vitesse

**Zones à risque** :
- Approche rapide
- Descente après montée
- Manoeuvres en turbulence
- Vol en haute altitude

**Formation** :
- Reconnaissance précoce
- Procédures d'évitement
- Entraînement simulateur

## Autres pannes majeures

### Panne électrique complète

**Causes** :
- Alternateur défaillant
- Batterie épuisée
- Court-circuit général

**Conséquences** :
- Pérte instruments
- Pérte radio/communication
- Pérte éclairage

**Procédures** :
- Atterrissage immédiat
- Plan B : Terrain dégagé identifié
- Communication : Mayday visuel

### Incendie moteur

**Reconnaissance** :
- Fumée dans cockpit
- Odeur brûlé
- Température moteur élevée

**Actions** :
1. **Coupe-feu** : Fermer immédiatement
2. **Collectif** : BAS pour autorotation
3. **Atterrissage** : Forcé, terrain adapté
4. **Évacuation** : Après arrêt complet

### Perte de carburant

**Symptômes** :
- Jauge baisse rapide
- Moteur hoquette
- Pression carburant nulle

**Gestion** :
- Atterrissage immédiat
- Terrain le plus proche
- Autorotation si nécessaire

## Préparation mentale aux urgences

### Gestion du stress

**Reconnaissance** :
- Accélération cardiaque
- Pensées confuses
- Actions précipitées

**Techniques** :
- Respiration profonde
- Procédures automatiques
- Focus sur actions immédiates

### Formation et entraînement

**Fréquence** :
- Théorie : Tous les 6 mois
- Simulateur : Tous les 3 mois
- Vol réel : Annuel minimum

**Contenu** :
- Procédures mémorisées
- Scénarios variés
- Débriefing détaillé

### Culture sécurité

**Rapport d'événements** :
- Analyse incidents
- Retours d'expérience
- Amélioration continue

**Prévention** :
- Maintenance rigoureuse
- Formation continue
- Vigilance permanente

## Synthèse du chapitre

Les urgences en hélicoptère exigent des réactions immédiates et précises. L'autorotation maîtrisée, la récupération LTE et l'évitement du vortex ring state forment le triptyque des compétences essentielles pour la survie.

Ces procédures, apparemment complexes, deviennent automatiques avec l'entraînement répété, transformant le stress en actions efficaces.
