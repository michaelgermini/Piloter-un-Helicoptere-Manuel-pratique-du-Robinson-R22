# Synthèses Visuelles - Chapitres 6 à 17 (Résumé consolidé)

## Chapitre 6 : Préparation avant vol
```
INSPECTION EXTÉRIEURE (10 positions) → CHECK-LIST DÉMARRAGE → MÉTÉO METAR/TAF
├── Pales, verrière, pitot            ├── Master ON, alternateur ON    ├── VFR minima
├── Rotor queue, train                ├── Mélange RICH, choke          ├── Conditions R22
├── Carénage, points d'attache        ├── Starter 5-10 sec             └── Décision vol
└── Carter, pneumatiques             └── Post-démarrage vérifications

BRIEFING SÉCURITÉ:
Météo → Plan vol → Urgences → Équipage
```

## Chapitre 9 : Approche et atterrissage
```
PLAN APPROCHE → ARRONDISSEMENT → ATTERRISSAGE → ARRÊT MOTEUR
├── Vitesse 60-70 kt, descente 300-500 ├── Hauteur 10-15 ft, collectif bas ├── Séquence arrêt 15-20 sec
├── Angle 3-5°, stabilisé            ├── Cyclique arrière, douceur      ├── Mélange RICH, alternateur OFF
├── Effet sol gestion               ├── Toucher léger                   └── Collectif bas, rotor arrêt
└── Check-list final                └── Redécollage si nécessaire       └── Post-arrêt inspection
```

## Chapitre 10 : Gestion des pannes
```
AUTOROTATION → LTE (LOSS OF TAIL ROTOR) → VORTEX RING STATE
├── Reconnaissance: RPM <430        ├── Nez dérive, pédales inop     ├── Vibrations, descente accélérée
├── Collectif BAS, cyclique avant   ├── Collectif BAS, accélération   ├── Collectif BAS, accélérer >40 kt
├── Vitesse 65 kt, RPM 350          ├── >50 kt récupération           ├── Sortie zone vortex
└── Récupération collectif lever    └── Pédales retrouvent efficacité └── RPM récupéré

PROCÉDURES URGENCE:
Feu → Coupe-feu, atterrissage forcé
Électrique → Atterrissage immédiat
Carburant → Terrain plus proche
```

## Chapitre 14 : Aérodynamique avancée
```
DISSYMÉTRIE DÉTAILLÉE → PRÉCESSION GYRO → COUPLE MOTEUR → FORCES INERTIELLES
├── ΔL = L_av - L_ar = ρ V² S Cl (Vr_av² - Vr_ar²)  ├── H = I Ω = 785 N⋅m⋅s   ├── C = P/Ω = 1'780 Nm
├── Compensation θ_correctif ≈ (Vt/Vh)×θ_moyen     ├── Précession 90°        ├── P_queue = C / bras
├── Limite course ±10°                             ├── Lead-lag, flapping     └── Équilibre dynamique
└── Vno 190 km/h limite                            └── Applications pratiques  └── G-force ≤2.0 R22

FIGURE DE MÉRITE M = 0.65-0.75
NOMBRE AVANCE μ = Vt/(Ω R) ≤0.4
```
